# Demo Script for Hackathon Video

**Duration:** Under 2 minutes
**Target:** Microsoft × Premier League Hackathon Judges

## Scene 1: Introduction (0:00 - 0:15)

**Visual:** Title screen with MatchMind AI branding

**Narrator:**
"MatchMind AI transforms synthetic football match events into explainable match intelligence. One moment. The evidence. The story."

**Action:** Fade to application homepage

## Scene 2: Match Dashboard (0:15 - 0:30)

**Visual:** Match list showing 12 synthetic matches

**Narrator:**
"Our dashboard displays 12 synthetic matches from our validated dataset. Each match shows teams, final score, and scenario type. Notice the AI mode indicator - we're running in demo mode with deterministic analysis."

**Action:** Click on a match (e.g., SYN-M001 - Northbridge FC vs Kingsford United)

## Scene 3: Match Overview (0:30 - 0:45)

**Visual:** Match detail page with score banner and Overview tab

**Narrator:**
"Here's the match detail view. The score banner shows Northbridge FC winning 3-2. The Overview tab displays comprehensive statistics - shots, corners, fouls, cards - all calculated from the actual event records."

**Action:** Scroll through statistics cards

## Scene 4: Event Timeline (0:45 - 0:55)

**Visual:** Switch to Timeline tab, scroll through events

**Narrator:**
"The Timeline tab shows every event chronologically. Goals, cards, substitutions - each event is timestamped and color-coded. You can filter by team, event type, or match period."

**Action:** Click on a goal event to show details

## Scene 5: Turning Points (0:55 - 1:10)

**Visual:** Switch to Turning Points tab

**Narrator:**
"Our turning-point engine identifies the most significant moments. This red card at 78 minutes scored highest. Each insight includes the explanation, ranking rationale, and score change. Every insight references the actual source events."

**Action:** Click on a turning point to see evidence

## Scene 6: AI Insights (1:10 - 1:30)

**Visual:** Switch to AI Insights tab, show Fan mode

**Narrator:**
"The AI Insights tab generates match recaps. In Fan mode, you get simple, engaging explanations. Switch to Analyst mode for detailed statistics and technical analysis. Ask any question about the match - goals, shots, fouls - and get evidence-backed answers."

**Action:** Toggle to Analyst mode, ask a question

## Scene 7: Personalization & Upload (1:30 - 1:40)

**Visual:** Show mode toggle, then navigate to Upload page

**Narrator:**
"Personalization adapts explanations to your audience. You can also upload your own CSV files for analysis - our validator checks required columns and previews the data before processing."

**Action:** Show upload interface with drag-and-drop

## Scene 8: Technical Summary (1:40 - 1:50)

**Visual:** Show architecture diagram or code structure

**Narrator:**
"Built with Spring Boot, React, Gemini, and synthetic data, our five-stage pipeline ingests, interprets, explains, renders, and personalizes match intelligence. DEMO mode remains available when Gemini credentials are not configured."

**Action:** Brief code or architecture view

## Scene 9: Conclusion (1:50 - 2:00)

**Visual:** Title screen with tagline

**Narrator:**
"MatchMind AI - explainable football match intelligence, grounded in evidence, personalized for every fan. Thank you."

**Action:** Fade to black, show hackathon branding

## Production Notes

### Visual Style
- Dark navy background (#0b1120)
- Football green accents (#22c55e)
- High contrast text
- Smooth transitions between scenes
- Show cursor movements clearly

### Audio
- Clear, professional narration
- Background music: subtle, upbeat
- No copyrighted music
- Volume balanced with narration

### Technical Details
- Screen resolution: 1920x1080 or higher
- Frame rate: 30fps
- Format: MP4 or WebM
- File size: Under 50MB for upload

### Recording Tips
1. Use screen recording software (OBS, QuickTime, etc.)
2. Practice the demo once before recording
3. Ensure backend and frontend are running
4. Close unnecessary applications
5. Test audio levels
6. Keep movements smooth and deliberate
